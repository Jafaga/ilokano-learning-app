# Ilokano Curriculum Design

This curriculum is designed for a Duolingo-inspired beginner learning flow. The course starts with immediately useful phrases before moving into identity, family, counting, colors, time, food, directions, conversation, and checkpoint review.

## Curriculum Principles

- Start with survival phrases learners can use immediately.
- Teach vocabulary in meaningful themes.
- Add grammar slowly through useful sentence patterns.
- Use repeated review across later lessons.
- Keep lessons short, but require mastery before unlocking the next level.
- Let contributors draft Ilokano content, then require human review before publishing.
